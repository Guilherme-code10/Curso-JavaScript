# 📚 Estudos de JavaScript

Repositório utilizado para registrar exercícios, desafios e pequenos projetos desenvolvidos durante meus estudos de JavaScript.

O objetivo é acompanhar minha evolução na linguagem e praticar conceitos fundamentais de programação.

## 🧠 Conteúdos praticados

- Tipos de dados
- Operadores matemáticos
- Operadores de comparação
- Estruturas condicionais
- Laços de repetição
- Funções
- Arrays
- Métodos de arrays
- Objetos
- Métodos de objetos
- Hoisting
- Callbacks
- Higher-Order Functions
- Entrada de dados pelo terminal
- Organização e legibilidade de código

## 🧪 Exercícios e desafios

O repositório contém diversos arquivos com exercícios separados por tema, além da pasta `desafios/`.
